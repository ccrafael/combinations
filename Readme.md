# Combinations generator 
This is just a simple project that creates combinations based on the 
algorithm  that can be found in The Art of Computer Programming Volume 4, Fascicle 3, Donald E. Knuth.

# Build (C++)
```
mkdir build
cd build
cmake ..
make
```

# Build (Rust)
To use the Rust implementation, navigate to the `rust` directory and use `cargo`:

**Run the application:**
```bash
cd rust
cargo run
```

**Run the tests:**
```bash
cargo test
```
